# data/

Small committed data files. Each is generated by a script in `scripts/` (re-runnable) or comes from an external source with its licence recorded here.

| File | What | Source / licence |
|---|---|---|
| `glass_4096.npy` | 4,096-particle relaxed SPH glass in the periodic unit box, Wendland C4 kernel (η = 1.6), density noise 0.13% | generated: `uv run python scripts/make_glass.py` (seed 1) |
| `glass_512.npy` | 512-particle glass, same method (noise 0.13%) | same script |

Both were regenerated on 2026-10-14 when the default kernel changed from the cubic spline to Wendland C4 (docs/DECISIONS.md, Step 3.6).
